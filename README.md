# 养成一个小魅魔 · 现代魅魔万人迷恋爱养成（女性向 BG 文字游戏）

从一枚会呼吸的蛋开始，把一只小魅魔养大，也同时被四个男人（以及你亲手养大的他）爱着。
纯前端视觉小说（Visual Novel），无需后端、无需安装，浏览器打开即玩。

## ✨ 核心卖点

- **养成主线**：蛋期 → 幼儿期 → 成长期 → 成熟期，四阶段成长，数值与剧情同步推进。
- **5 位可攻略对象 + 1 位隐藏真结局**：
  - 塞拉斯（你亲手养大的小魅魔，年下核心线）
  - 顾淮（镜头后面的暴君 · 摄影师）
  - 沈砚（住 2306 的沈医生）
  - 江屿（潮汐Livehouse 的门面 · 主唱）
  - 霍青（江边那家酒吧的老板）
  - 路西恩（隐藏「双生」真结局）
- **14 个分支结局**：5 个长文本结局 + 9 个短文本结局，全部含完整可玩内容。
- **R18 剧情**：文学性、细节化、高强度直白描写，全部发生在「成熟期 / 成年角色」之间；
  幼儿期与成长期绝不涉及任何性相关内容（硬性边界）。
- **多分支选项**：不同选择 → 不同性格倾向、不同好感、不同结局。

## 🎮 玩法与界面

- **18+ 准入**：进入游戏前需确认已满 18 岁并开启 R18 内容（可在设置中随时关闭）。
- **帅哥立绘**：每位男主均有立绘，支持多种表情变体，全程外观一致。
- **看立绘模式**：点击「👁 看立绘」或画面任意处，隐藏文字界面、查看完整立绘与背景；
  再次点击复原（也可在设置中关闭 BGM、调节音量）。
- **自动切换背景**：场景切换自动更换背景图，文件夹已有图优先复用，缺失部分已生成补充。
- **状态栏 / 图鉴**：随时查看爱意值、亲密值与各角色好感；通关后可在图鉴重温结局。
- **存档 / 读档**：本地自动存档，可手动存档与读档。
- **BGM**：内置程序化合成的环境氛围音乐（Web Audio，无需外部音频文件）。

## 🚀 本地运行

直接用浏览器打开 `index.html` 即可（需通过 http(s) 协议，部分浏览器对 `file://` 下的
ES Module 有跨域限制，建议用本地静态服务器）：

```bash
# 任选其一
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 📦 部署（GitHub Pages）

本仓库已配置为可直接托管为静态站点：

1. 将本目录内容推送到 GitHub 仓库；
2. 在仓库 **Settings → Pages** 中选择分支（如 `main`）与根目录（`/root`）；
3. 访问 `https://<用户名>.github.io/<仓库名>/` 即可在线游玩。

## ⚠️ 内容声明

本作为架空现代都市背景的成人向恋爱养成文字游戏，唯一奇幻因素为「魅魔」。
所有 R18 内容均发生在成年角色之间，请已满 18 周岁的玩家在理解前提下体验。
